# M24 — A mod speaks

Four commits on `m24-mod-strings`: the record at its gate, the engine import, the lab and its
demonstration mod, and the documents. Decided by [ADR-0021](../adr/0021-mod-messages.md), now
Accepted with four dated changes.

## What this milestone was for

The second of the three items M17 left open, taken in the order the owner chose on 2026-09-24.
`DEFERRED.md` recorded a string API for mods with its trigger: a mod that has something to say
to a person. **That trigger had not fired, and ADR-0021 says so first.** No mod in the
repository has anything to say to anybody. The consumer is the lab's own `herald.wasm`, written
for this milestone, which proves the path works and proves nothing about demand.

## What was built

**One import, one way.** `atlas_say(key, key_len, args, arg_count)` names a key suffix and up to
four 64-bit integers. The host prefixes `mod.<name>.`, so a mod names only its own words, and
queues the message for the application. Nothing comes back: no import returns resolved text, a
length, or whether a key exists. Text going *into* a mod was ruled out rather than deferred,
because resolved text depends on the locale and two lockstep peers need not share one.

**Refusals, in order.** Everything judged without touching guest memory is judged first, so a
malformed call is a status the mod can see rather than a trap. A bad key or too many arguments
is `ATLAS_ERR_RANGE`. A spent per-tick budget or a full queue is `ATLAS_ERR_EXHAUSTED`, dropped
and counted. An argument pointer outside the mod's memory traps and disables the mod, which is
ADR-0015's rule for any bad pointer.

**A mod's table.** `<name>.strings.json` beside the module, read through the same mount and
validated path. Every key must lie under the mod's prefix or the table is refused whole, and the
mod runs anyway with its keys showing as themselves. An accepted table joins the application's
catalogue through `Catalog::add_table`.

**The lab.** It drains messages after each poll, resolves and substitutes them in its own
language, prints them and logs them. The summary line gains how many were said and how many were
dropped. `tools/gen_mods.py` generates `herald.wasm`, which says `mod.herald.bell` with the tick
every twentieth tick; the two existing mods regenerate byte-identical.

```
mod 'herald.wasm' says: The herald rings at tick 20
```

## What changed from the record

Each is a dated note at its own decision in ADR-0021.

- **D1 made precise.** The key's character set and length, judged-before-memory ordering, and
  the trap for a bad argument pointer were not in the sketch.
- **D4's budget moved** from `ModLimits` to `ModHostConfig`. The limits bound what a guest costs
  the runtime; these bound what the host holds for an application, beside the log's rate limit.
- **D5 has no panel.** The overlay's log console already shows, filters and scrolls these lines.
  Under lockstep the lab passes no catalogue, so messages show as keys; nothing diverges, because
  nothing said is compared.
- **`--text-check` cannot check a mod's keys.** They are chosen at run time by a guest, so there
  is no list to resolve. The namespace check on the table is what can be checked, and is.

## Checks

Seven guest tests in `engine/script/tests/test_mod_messages.cpp`, each through a module built
byte by byte. Two integration cases in `tests/integration/lab_checks.py`:

- **The herald speaks by key.** Resolved words at ticks 20 and 40, and a final hash equal to a
  run with no mod, because speaking is presentation.
- **The table is fenced.** A table naming `mod.rival.bell` is refused, its own key with it, and
  the mod keeps speaking. The foreign key is one nothing else defines, so the catalogue's own
  clash check cannot be what catches it. An earlier draft used an engine key and was caught only
  by a log message's wording; the mutation below found that.

Ten mutations, each caught by the named test:

| Mutation | Caught by |
|---|---|
| No namespace prefix on the key | message arrives in the mod's own namespace |
| Any key suffix accepted | malformed call is refused |
| Per-tick budget never spent | bounded per tick |
| Queue bound ignored | never drains cannot be made to hold more |
| A table naming anything accepted | a mod's table may name only its own keys |
| The lab never adds the table | `mod_speaks_by_key` |
| The lab skips the namespace check | `mod_table_is_fenced` |
| No catalogue on the main path | `mod_speaks_by_key` |
| No substitution of arguments | `mod_speaks_by_key` |
| Messages never drained | both cases |

The second engine mutation's first form did not compile, so its apparent failure came from the
previous mutant's binary. It was rerun as a compiling variant and caught. A restore once
landed in the same second as a mutant's build, and ninja kept the stale binary; the loop now
touches the file after restoring.

## Verification

Commands run on macOS arm64, Debug:

```bash
cmake --build --preset macos-debug
ctest --preset macos-debug -j8
tools/format.sh --check
ATLAS_CLANG_TIDY=/opt/homebrew/opt/llvm@23/bin/clang-tidy tools/tidy.sh macos-debug
python3 tools/check_module_deps.py
python3 tools/check_spdx.py
python3 tools/gen_mods.py --check
```

| Check | Result |
|---|---|
| Test suite | 1045 of 1045 passed |
| clang-tidy 23 | clean |
| Format, module boundaries, SPDX, mod currency | clean |
| Golden hashes | unchanged; no simulation code was touched |

**A pre-existing test isolation race was seen twice and is not fixed here.** Two assets tests
failed once each under `ctest -j8` and passed on rerun, 20 of 20 alone. Their scratch
directories are named from a per-process counter that starts at zero, and ctest runs each case
as its own process, so two parallel cases can share a directory and one deletes the other's
files. It is flagged as a separate task.

## What is not proved

- **That any mod wants this.** The herald exists to exercise the path.
- **A windowed run showing a message.** The log console is where it would appear. No test opens
  a window with a mod loaded, and no one has looked.
- **Words under lockstep.** Two peers print keys, by the recorded choice above.

## Benchmark impact

None measured. The import runs only when a mod calls it, and a mod that does not speak pays one
empty queue drain per tick in the lab.

## The next smallest slice

removing a peer is visible to the simulation: every remaining peer must apply the drop at the
same tick or diverge, which is an agreement protocol ADR-0017 deliberately deferred.
